# Tumor Angiogenesis Modeling

Mathematical modeling project studying tumor growth, VEGF diffusion, angiogenesis and the impact of chemotherapy.

## Overview

This project develops and simulates a spatial-temporal mathematical model of tumor progression. The model combines partial differential equations (PDEs) for spatial processes with ordinary differential equations (ODEs) for selected biological dynamics.

The objective is to explore how tumor growth, vascular signalling through VEGF and chemotherapy interact over time and space.

## Model components

- tumor growth dynamics;
- VEGF production and diffusion;
- angiogenesis-related interactions;
- spatial-temporal evolution of the system;
- simulation of chemotherapy effects.

## Methods

- **Python** for numerical simulation and analysis
- **NumPy** for numerical computation
- **Matplotlib** for visualization
- **PDE / ODE modeling** for biological dynamics
- reaction-diffusion modeling for spatial processes
